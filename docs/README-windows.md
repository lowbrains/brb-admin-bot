# Администратор БРБ: подключение Telegram

1. Откройте start.cmd двойным щелчком.
2. Вставьте токен своего бота из BotFather и нажмите Enter. Ввод скрыт. Токен хранится только в памяти процесса; его нужно вводить при каждом запуске.
3. При первом запуске скопируйте показанную команду /connect@brb_team_admin_bot с одноразовым кодом в нужную группу Telegram. Код действует 15 минут. Если время истекло, перезапустите программу.
4. Вернитесь в окно программы, проверьте название группы и введите ДА. Программа отправит подтверждение подключения в эту группу.
5. В группе отправьте /ping@brb_team_admin_bot и /team@brb_team_admin_bot.

Бот отвечает только в привязанной группе. Доступ определяется членством в этой закрытой группе; персональная идентификация девяти сотрудников пока не реализована. Личные сообщения и другие группы игнорируются.

connection.json содержит идентификатор группы и позицию чтения сообщений, но не токен. Не запускайте несколько копий программы, в том числе на других компьютерах через OneDrive. Для остановки закройте окно или нажмите Ctrl+C.

Нужны Windows PowerShell 5.1 и интернет. Дополнительные библиотеки не нужны. start.cmd применяет ExecutionPolicy Bypass только к запускаемому процессу, не меняя постоянные настройки Windows. Корпоративная групповая политика может запретить запуск.

Это проверочная версия: /ping, /team, /help. ИИ-ответы, календарь, учёт отпусков, задачи и рассылки ещё не реализованы. Автозапуска нет; программа работает, пока открыто её окно и ноутбук не спит.

Основа подключения: https://core.telegram.org/bots/api#getupdates
